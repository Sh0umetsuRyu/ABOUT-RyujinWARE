# RyujinWARE™

**Independent Software Development | Reverse Engineering | AI Research | Operating System Development**

RyujinWARE™ is an independent software development initiative founded by Shoumetsu Ryu (Reshii S.), focused on Linux applications, reverse engineering, artificial intelligence, firmware development, and operating system engineering.

Our work spans practical desktop software, embedded hardware research, and experimental system technologies. Each project is developed with an emphasis on functionality, hardware compatibility, user control, and long-term maintainability.

## Current Projects

### RyuSCOPE GS
**In Development | Preparing for Initial Release**

RyuSCOPE GS is a graphical interface for Gamescope on Linux, designed to simplify game launching, resolution scaling, display configuration, and performance monitoring.

The application provides a centralized interface for managing Gamescope parameters without requiring users to configure launch commands manually.

Development includes Steam integration, MangoHUD support through Gamescope, and additional display and performance configuration. Future plans include frame-generation support and LACT integration.

RyuSCOPE GS is currently the primary application being prepared for public release.

### RyuSECT
**In Development**

RyuSECT is an AI-assisted binary indexing and analysis tool intended for executable inspection, firmware research, and reverse engineering.

The project focuses on identifying binary structures, organizing analysis results, and improving workflows for examining compiled software and embedded firmware.

Future integration with RyuKORE is planned to provide additional AI-assisted analysis capabilities.

### RyuFORGE
**Planning Stage**

RyuFORGE is a proposed development toolkit for kernel and binary creation, code generation, compilation, firmware construction, and validation.

The project is intended to complement RyuSECT by providing construction and development capabilities alongside binary analysis.

AI-assisted workflows and integration with other RyujinWARE development utilities are part of the long-term design.

### RyuKORE
**Planning Stage**

RyuKORE is a reusable AI engineering platform intended to provide shared AI functionality across RyujinWARE applications.

Rather than developing separate AI systems for individual tools, RyuKORE is being designed as a common foundation for analysis assistance, development workflows, and future system-level integration.

RyuKORE is separate from the Echo Fox AI™ personal assistant project, although interoperability between the two is planned.

### RyuSpark Cinder / Terra
**In Development**

RyuSpark Cinder / Terra is a multi-platform gaming frontend and firmware development project targeting embedded handheld systems.

Initial development focuses on HiChip HC16xx MIPS hardware and Rockchip ARM-based devices.

Research includes custom firmware, boot processes, hardware compatibility, embedded Linux, and gaming frontend development.

The long-term objective is to support a broader range of handheld platforms while maintaining hardware-specific optimization and compatibility.

## Long-Term Development

Beyond the current application lineup, RyujinWARE is researching independent operating system technologies, AI-native kernel architecture, and hardware-aware computing.

These initiatives include the proposed Raijin OS family and RyuKERNEL, an independently developed kernel architecture intended to support local AI integration, user-controlled configuration, and Linux interoperability.

These projects remain in architectural research and are not currently available as functional operating systems.

## Development and Availability

RyujinWARE is in its early development stages. Individual projects will be published as they reach suitable milestones for testing and public use.

Development builds may contain incomplete functionality, limited hardware support, or experimental features. Project-specific repositories will provide release information, known limitations, documentation, and licensing details.
